# ElliFit

Lokale Auswertung monochromatischer Ellipsometrie mit globaler Suche nach Schichtdicke und/oder Brechungsindex.

Der rekonstruierte Programmstand wird auf dem Branch **ellifit-1.1** bereitgestellt:

- [Quellcode und ausführliche Anleitung](https://github.com/kangaroocry/ElliFit/tree/ellifit-1.1)
- [Programm als ZIP herunterladen](https://github.com/kangaroocry/ElliFit/archive/refs/heads/ellifit-1.1.zip)

ZIP vollständig entpacken, Python 3.11 oder neuer (64 Bit) installieren und `Start_Windows.bat` doppelklicken. Beim ersten Start werden Abhängigkeiten aus dem Internet installiert. Anschließend läuft das Programm lokal mit Browseroberfläche. Die Wellenlänge ist editierbar und auf 632,8 nm voreingestellt.

Materialwerte im Programm sind Beispiele und müssen zur tatsächlichen Probe passen. Windows 7 wird von diesem Stand nicht unterstützt. Dieser Quellstand ist keine fertig kompilierte Windows-EXE.

Details zum Funktionsumfang und zum aktuellen Prüfstand stehen in der README auf dem Programmbranch. Ursprüngliche Messdateien und das beigefügte Handbuch werden nicht veröffentlicht.
