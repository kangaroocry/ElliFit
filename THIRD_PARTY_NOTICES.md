# Drittanbieter

Die Abhängigkeiten werden aus PyPI installiert und behalten ihre jeweiligen Lizenzen:

| Paket | Verwendung | Lizenz |
|---|---|---|
| NumPy | Numerik | BSD |
| SciPy | Optimierung | BSD |
| FastAPI / Pydantic | Lokaler Server / Eingabevalidierung | MIT |
| Uvicorn | HTTP-Server | BSD |
| python-multipart | Messdateiimport | Apache 2.0 |
| Plotly / Plotly.js | Lokal bereitgestellte Diagrammbibliothek | MIT |
| pytest / httpx / tmm | Entwicklung und Referenztests | Siehe jeweilige Pakete |

Die vollständigen Lizenzen liegen in den installierten Distributionen. Plotly.js wird aus dem installierten Plotly-Paket lokal ausgeliefert. Das öffentliche Repository enthält weder das ursprüngliche Handbuch noch die hochgeladenen Messdateien.
